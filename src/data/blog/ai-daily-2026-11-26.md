## 导读

跨语言会议里，翻译什么时候开始和译得准不准同样重要。抢在说话人讲完整句话之前翻译，可能漏掉句尾的否定。多等几秒，听众又容易跟不上讨论。北京时间 11 月 26 日，DeepL 针对这一难题发布新模型，千问则扩展了语音识别、语音合成和实时对话的语言覆盖。

今天也有几项进展发生在用户看不到的地方。美国监管机构公布了 SpaceX 轨道数据中心的授权条件，OpenAI 开始小范围试用新的推理隐私保护，Anthropic 公开了它如何验证线上接口迁移。另有工具开始支持按历史时点搜网页、在不同模型之间复用长文计算结果，以及把 Obsidian 笔记库接入智能体。

## 今日要点

- DeepL 在东京发布 Aure v2，首批支持六种语言。公司测得翻译开始前的等待时间中位数比上一代减少一半。[DeepL 发布公告](https://prtimes.jp/main/html/rd/p/000000076.000112534.html)
- 千问扩展 Qwen-Audio-3.1 的多语能力，公告分别列出语音识别 59 种、语音合成 65 种和实时对话 53 种语言。[千问更新公告](https://x.com/Alibaba_Qwen/status/2125798914490249411)
- 美国联邦通信委员会公布 Starmind 附条件授权，涉及最多 100 万颗轨道计算卫星的备用与应急测控。[授权决定](https://docs.fcc.gov/public/attachments/DA-26-1273A1.pdf)
- OpenAI 确认少量客户正在试用私密推理，保护范围指向模型处理中的提示和响应。[试点公告](https://x.com/sama/status/2125638790593274259)、[产品说明](https://openai.com/business/private-intelligence/)
- Anthropic 公开消息接口从 Python 迁到 Rust 的验证过程，公司报告迁移后每请求的处理器用量约降 70%。[Anthropic 工程复盘](https://www.anthropic.com/research/migrating-api-to-rust)
- Perplexity 推出 Time Machine，开发者可以给网页搜索和正文提取设同一个历史截止时间。[功能公告](https://www.perplexity.ai/en-GB/hub/blog/freeze-the-web-with-perplexity-time-machine)
- Ramp Labs 与 Base Labs 公布跨模型缓存转换研究，在七个模型之间尝试复用已经完成的长文计算。[技术报告](https://labs.baseten.co/articles/speculative-encoding-many-to-many-cache-translation)
- Obsidian 宣布提供官方连接器，并公开了教智能体读写笔记与画布的操作指南。[Obsidian 发布公告](https://x.com/obsdmd/status/2125700941156651151)、[连接器文档](https://obsidian.md/help/connectors)

## 重点进展

以下各节的“为什么重要”和文末的“值得关注”为编辑分析。

### DeepL 怎样缩短实时翻译的等待时间？

**发生了什么**

DeepL 在东京推出 Aure v2，首批支持日语、英语、德语、法语、西班牙语和韩语。支持的语言会自动应用到 DeepL Voice 的线上会议、面对面对话和语音应用编程接口（API）。模型把从原声到译文语音的处理整合到一起，并通过训练学习何时已有足够上下文可以开口翻译。[DeepL 发布公告](https://prtimes.jp/main/html/rd/p/000000076.000112534.html)

DeepL 在内部测试中测得，从说话到翻译开始的等待时间中位数比上一代减少 50%。该指标衡量的是译声何时开始。厂商也公布了英译日的错误对比，结果对应其选用的测试语料和系统配置。[DeepL 测试说明](https://prtimes.jp/main/html/rd/p/000000076.000112534.html)

**为什么重要**

翻译开始得更早，其他人更容易接话。对跨国会议来说，还应观察模型遇到句尾否定、数字或多人同时说话时的表现。开始播放的速度和整句话翻译的正确率都影响交流。

### 千问的三个语音入口各自扩展了什么？

**发生了什么**

千问团队为已有的 Qwen-Audio-3.1 系列扩大多语支持。公告所列的三个 Flash 接口中，语音识别覆盖 59 种语言，负责把录音转成文字。语音合成覆盖 65 种语言，负责把文字读出来。实时对话覆盖 53 种语言，支持流式语音交互。团队同时公布了各入口的中文方言覆盖。[千问更新公告](https://x.com/Alibaba_Qwen/status/2125798914490249411)、[语音识别模型卡](https://www.qwencloud.com/models/qwen-audio-3.1-asr-flash)、[语音合成模型卡](https://www.qwencloud.com/models/qwen-audio-3.1-tts-flash)、[实时对话模型卡](https://www.qwencloud.com/models/qwen-audio-3.1-realtime-flash)

**为什么重要**

客服系统即使已经能把一种方言转写成文字，实时接听或用指定音色回话仍要分别验证。语言覆盖数量适合用来筛选接口，实际选型时还要用来电录音检查错字、响应时间和打断后的表现。

### FCC 对 Starmind 的授权覆盖哪些操作？

**发生了什么**

美国联邦通信委员会（FCC）对 SpaceX 的 Starmind 申请作出附条件授权。决定书列出的星座规模上限是 100 万颗卫星，获准使用的无线电频谱限于备用和应急的遥测、跟踪与指令通信。SpaceX 计划以光链路承担常规通信。监管机构暂缓决定关于部分卫星退役处置方式的豁免请求。[FCC 决定书](https://docs.fcc.gov/public/attachments/DA-26-1273A1.pdf)

决定书要求首颗获授权卫星在 2033 年 11 月 25 日前完成部署并运行。截至 2035 年同日须完成授权规模的 10%，2038 年达到 50%，2040 年完成全部部署。这些是维持授权的条件，实际建设进度要看后续部署。[FCC 决定书第 10 段](https://docs.fcc.gov/public/attachments/DA-26-1273A1.pdf)

**为什么重要**

轨道计算设施需要在常规链路失效时仍能回传状态并接收控制指令。这份决定给出了备用通信的监管条件。评估轨道算力能否规模化，还需要看首批设备的散热、链路可用性和在轨维护数据。

### OpenAI 正在测试哪一种推理隐私保护？

**发生了什么**

OpenAI 首席执行官 Sam Altman 确认，少量客户正在测试 Private Inference（私密推理）。OpenAI 将其标为早期测试，并描述为把机密计算和严格的访问控制结合起来，保护模型处理过程中的提示和响应。公司的企业产品页也单独列出了零数据保留，其范围是符合条件的 API 在处理结束后对提示和响应的留存。[Altman 的试点公告](https://x.com/sama/status/2125638790593274259)、[OpenAI 隐私产品说明](https://openai.com/business/private-intelligence/)

**为什么重要**

把合同交给模型审阅时，团队需要知道它在传输、计算和处理结束后分别受到什么保护。控制保存时长和限制计算期间的访问解决的是两个环节的问题。评估这项试点时，值得看哪些处理步骤有可核验的保护，以及外部工具调用是否在覆盖范围内。

### Anthropic 怎样验证线上接口迁移后的行为？

**发生了什么**

Anthropic 发布工程复盘，说明它如何把 Claude 的消息接口（Messages API）从 Python 迁到 Rust。团队把真实流量的一份副本交给新服务，让旧服务继续对用户响应，并在接收请求、解析设置、构造提示等步骤逐项比对。工程师记录差异出现的位置和长度等特征，Claude 根据这些记录提出修复，团队再用生产流量副本复核。[Anthropic 工程复盘](https://www.anthropic.com/research/migrating-api-to-rust)、[Anthropic 发布记录](https://x.com/AnthropicAI/status/2125627317263466739)

公司报告迁移期间服务保持在线，单请求处理器用量约降 70%。图表所用的处理器数据来自一个服务区域，首个词元的等待时间中位数约降 20%，该项来自较短时段的 Claude Code 客户请求。当天公开的是迁移复盘，公开流量已于 9 月切换。[Anthropic 工程复盘及图 15、16](https://www.anthropic.com/research/migrating-api-to-rust)

**为什么重要**

线上接口的调用方可能依赖文档或测试没有覆盖的细节，例如某种输入触发的错误返回。逐步比较同一请求在两个版本中的处理结果，可以缩小故障范围，也让团队有具体证据决定何时切换。

### Perplexity 怎样把搜索限制在某个历史时点？

**发生了什么**

Perplexity 为搜索和网页正文接口推出 Time Machine。开发者可以给两次请求传入同一个截止时间，最远回看 365 天。搜索用截止时间前最后保存的副本生成标题和摘要，正文接口可以读取同一时点的版本。没有相应副本时，搜索和读取可能返回较少结果或缺少正文。[Perplexity 发布公告](https://www.perplexity.ai/en-GB/hub/blog/freeze-the-web-with-perplexity-time-machine)、[Time Machine 开发文档](https://docs.perplexity.ai/docs/search/time-machine)、[开发团队发布记录](https://x.com/perplexitydevs/status/2125676416834605488)

**为什么重要**

让模型重做昨天的预测时，今天的网页往往已经补上了结果。固定网页版本可以减少这种信息泄露，也便于比较模型升级前后的表现。复测时还需要记录哪些网页缺少快照，免得把缺失资料造成的差异归到模型头上。

### 两个不同模型能否复用同一份长文的计算结果？

**发生了什么**

Ramp Labs 与 Base Labs 公布一项跨模型缓存转换研究。模型读入长文时会保留已经计算的中间信息，供后续生成使用，这部分通常叫键值缓存（KV cache）。研究者用一个 23.5 亿参数的转换模型把这种信息从一个模型的格式转为另一个模型的格式，覆盖七个模型之间的 42 个有方向的组合。团队也公开了实验权重。[技术报告](https://labs.baseten.co/articles/speculative-encoding-many-to-many-cache-translation)、[Ramp Labs 发布记录](https://x.com/RampLabs/status/2125627502802653330)、[公开权重](https://huggingface.co/RampPublic/speculative-encoding)

团队测得，在最长 8,192 个词元的测试文档上，转换后的平均准确率是目标模型自行读入原文时的 96.9%。在约 3.2 万词元的长文选择题实验中，源模型已完成计算时，目标模型约快四倍开始作答，准确率保留超过九成。这两项结果采用不同的文档长度和测试设置。[技术报告第 6 至 11 节](https://labs.baseten.co/articles/speculative-encoding-many-to-many-cache-translation)

**为什么重要**

一份合同如果先交给一个模型找条款，再交给另一个模型检查矛盾，两次读入整份材料会重复计算。转换缓存有机会减少第二次等待，采用前还要把首次计算、缓存传输和转换开销一起计入，再检查开放式任务中的回答质量。

### Obsidian 的连接器能让智能体怎样使用笔记库？

**发生了什么**

Obsidian 宣布提供面向 AI 智能体的官方连接方式。文档列出了 Claude、ChatGPT、Cursor 等安装入口，并公开了供智能体加载的操作指南。指南覆盖 Obsidian 的 Markdown 写法、画布和资料库。安装了相应命令行工具的环境，还可让智能体搜索、读取和管理笔记。不同客户端能用的操作取决于其运行环境。[Obsidian 发布记录](https://x.com/obsdmd/status/2125700941156651151)、[连接器文档](https://obsidian.md/help/connectors)、[开放指南仓库](https://github.com/obsidianmd/obsidian-skills)

**为什么重要**

如果多种助手都能读懂同一份项目笔记，交接时就不必为每个助手重复说明链接和字段的写法。对长期使用的笔记库，能否限定可读范围、审阅批量改动和恢复旧版本，会直接影响这类连接是否适合日常使用。

## 值得关注

- **轨道计算的首批实测。** 后续可以关注首颗 Starmind 卫星的在轨运行，以及授权所要求的避碰、退役和实际部署记录。[FCC 决定书](https://docs.fcc.gov/public/attachments/DA-26-1273A1.pdf)
- **历史搜索的复测条件。** 同一组历史问题可以用固定时间反复测试。记录快照缺失率以及正文接口是否取到同一版本，能帮助解释分数变化。[Time Machine 开发文档](https://docs.perplexity.ai/docs/search/time-machine)
- **跨模型复用的实际收益。** 长文选择题能验证转换后的缓存还保留多少信息。后续可以看开放式写作和多文档核对的效果，以及源、目标模型分布在不同机器时的总用时。[Ramp Labs 与 Base Labs 的技术报告](https://labs.baseten.co/articles/speculative-encoding-many-to-many-cache-translation)
