## 导读

让 AI 完成一项实际工作，往往要同时决定三件事：用哪个模型、怎样找到最新资料，以及哪些动作必须受到限制。模型得分提高只是其中一部分，信息获取、运行成本和产品规则也会改变使用体验。

10 月 17 日值得注意的进展覆盖了这些环节：DeepSeek 同时更新模型和信息检索接口，NVIDIA 尝试让同一份小模型权重适应不同计算预算，Apple 与 Claude Code 则分别调整应用审核要求和编程助手的运行行为。本期收录 5 项，模型更新与搜索服务分别说明，不将二者混为同一种能力。

本文按 Asia/Shanghai（北京时间）统计 2026 年 10 月 17 日 00:00—23:59 内正式公开的进展。海外发行时间按带时区记录换算；DeepSeek 搜索服务依据中国发布方标注的当日更新记录归类，不推断具体上线分钟。“发生了什么”整理来源事实及发布方表述，“为什么重要”和“值得关注”为编辑分析；本期未运行模型、测试付费接口或独立复现评测。

## 今日要点

- DeepSeek-V4.1-Flash-1017 更新网页、应用和 API 使用的模型，调用名称与价格不变，并提供 MIT 许可权重。
- DeepSeek 开放独立的 Search 与 Fetch 接口，分别用于查找网页和提取单页内容，费用按成功请求计算。
- NVIDIA 发布 Dory1.0-4B，通过重复使用部分网络层调整推理计算量；更多循环并不保证所有任务都更好。
- Apple 在审核规则中明确覆盖 AI 生成的非自愿私密影像，并进一步明确禁止审核后暗中启用未申报功能。
- Claude Code v2.1.302 增加自动模式分类器配置和空闲压缩开关，并调整子任务的默认运行方式。

## 重点进展

### DeepSeek 的 Flash 更新改变了什么？

**发生了什么**

DeepSeek 发布 V4.1-Flash-1017，官方更新日志称网页、应用与 API 已切换到新版本；API 继续使用 `deepseek-flash`，调用方式和价格保持不变。更新重点包括推理、编程、工具任务和视觉评测表现，以及减少输出长度和任务运行时间。[来源：DeepSeek 更新日志](https://api-docs.deepseek.com/updates/)

官方模型卡同时提供 MIT 许可权重，列出的 Terminal-Bench 4.0 得分从上一版的 31.2 提高到 42.3。这个基准检查模型在终端中完成任务的能力；成绩来自发布方，且该项使用 Claude Code 执行框架，不能当作任意工具组合下的成功率。官方仓库的发布提交时间为北京时间 10 月 17 日 13:46:55。[来源：模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)、[提交记录](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017/commits/main)

**为什么重要**

调用名称不变，降低了升级接入的改动量，也意味着只记录模型别名可能不足以重现旧结果。维护自动化任务的团队应保留运行日期、实际配置和验收样例，检查同一任务的完成质量、重试次数与总费用。厂商报告输出变短，并不等于每个业务任务都会更便宜。

### DeepSeek 的搜索接口与模型调用有什么区别？

**发生了什么**

DeepSeek 在 10 月 17 日更新日志中宣布开放自有搜索服务。配套文档说明，Search 接口返回结构化网页搜索结果，Fetch 接口把单个网页提取为 Markdown；二者使用 API 密钥认证，可以作为程序单独调用的工具。[来源：开放公告](https://api-docs.deepseek.com/updates/)、[Search 与 Fetch 文档](https://api-docs.deepseek.com/guides/search/)

文档列出的价格均为每千次成功请求 0.75 美元，不按返回结果条数或词元计费；空搜索结果、失败与超时不收费。通过 DeepSeek API 在 DeepSeek Harness、Claude Code 或 Codex 中触发的服务端工具调用，目前免费，计划自北京时间 11 月 1 日 00:00 起按请求计费。直接接口价格与这项过渡安排应分别理解。[来源：计费说明](https://api-docs.deepseek.com/guides/search/#billing)

**为什么重要**

把搜索与网页读取拆成独立步骤，开发者便能决定何时搜索、读取哪些页面，以及怎样保留原始链接。例如日报程序可以先找候选，再逐页核对公告，而不是只接收模型整理好的结论。

不过，搜索返回的摘要、日期和权威性评分仍需核查，网页提取也受目标站可用性与访问政策限制。接口开放提供了信息获取手段，并不能替代来源验证；估算费用时，还应将检索请求与模型推理分别计算。

### Dory 4B 怎样用同一份权重调整计算量？

**发生了什么**

NVIDIA 发布约 40 亿参数的 Dory1.0-4B。它在生成时重复运行一组共享网络层，使用者可以选择循环次数，无需为此重新训练或更换模型；模型卡列出最高 256K 词元上下文、英语支持和 OpenMDW 1.1 许可。官方权重提交时间为北京时间 10 月 17 日 02:26:17，页面所写的海外发布日期为 10 月 16 日。[来源：NVIDIA 模型卡](https://huggingface.co/nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-BF16)、[仓库日期记录](https://huggingface.co/api/models/nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-BF16/commits/main)

NVIDIA 的自测中，SWE-bench Verified 编程任务得分从一次循环的 50.3 提高到四次循环的 61.8，但部分推理项目在四次循环时略低于两次循环。模型卡还说明，vLLM 的支持仍在合并审查中，当前需要相应分支。下载到权重，不等于常用推理软件的正式版本已经支持。[来源：评测与部署说明](https://huggingface.co/nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-BF16)

**为什么重要**

可以把这种设计理解为同一套处理步骤多做几遍：参数没有成倍增加，每个输出单位的计算却增加了。它为小模型提供了一种可调计算预算的方式，但选择循环次数时，需要同时测量正确率、输出长度、内存和整个任务的等待时间。更少的输出词元不能直接证明总计算成本更低。

### Apple 对 AI 生成影像明确了哪些审核要求？

**发生了什么**

Apple 更新 App Review Guidelines，明确第 1.2 条的内容治理要求覆盖非自愿私密影像，包括使用 AI 工具生成的此类内容。公告要求相关应用主动防止和移除这些内容；未采取足够防护、或收到通知后未修复违规的开发者，可能面临行为准则违规及应用下架。[来源：Apple 专项公告](https://developer.apple.com/news/?id=vvzx6cul)

新增编号 2.5.19 进一步明确既有的禁止隐藏、休眠或未申报功能的政策，涵盖通过审核后才启用有害功能的行为。官方 RSS 将专项公告标为美国太平洋夏令时 10 月 16 日 13:00:56，换算为北京时间 10 月 17 日 04:00:56；规则修订汇总于随后发布。[来源：规则变更汇总](https://developer.apple.com/news/?id=92th7e5i)、[官方 RSS](https://developer.apple.com/news/rss/news.rss)

**为什么重要**

生成图片的应用需要检查的不只是用户上传的材料，也包括模型可能生成的结果和审核后的功能变化。对产品团队而言，这使内容处理、举报响应与版本发布成为同一项持续工作。此次报道的是平台规则的明确与扩展，不能据此认定所有违规应用已经被发现或移除。

### Claude Code 如何调整自动模式和后台任务？

**发生了什么**

Claude Code 于北京时间 10 月 17 日 04:53:06 发布 v2.1.302。发行说明新增 `CLAUDE_CODE_AUTO_MODE_MODEL`，用于选择客户端自动模式分类器所用的模型，并明确它不改变服务端分类器；配置页面也增加空闲时压缩对话内容的开关。[来源：官方发行说明](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

该版本将继承当前上下文的 fork 子任务默认启用到更多运行入口，并让桌面应用和 VS Code 中主会话派出的子任务始终在后台运行；同一事件的自动触发脚本最多同时运行 12 个，其余等待。发行说明还列出拒绝读取超过 128 MB 的图片来源、修复部分设置写入丢失等问题。这些均按维护者说明报道，未独立验证修复效果。

**为什么重要**

编程助手的可靠性不仅取决于生成代码，也取决于任务怎样并发、配置何时保存，以及自动检查由什么组件处理。升级后，应重点检查原有脚本是否依赖旧的前后台行为，任务完成状态是否容易辨认。分类器可配置，也不能代替项目自己的工具权限和结果验收。

## 值得关注

### 如何判断更新是否真的降低了任务成本？

DeepSeek 强调缩短输出与运行时间，Dory 则允许增加模型内部计算。比较这两类变化时，适合记录同一组任务的完成率、总耗时、重试和实际账单；只看输出长度、参数量或某项基准分数，很容易漏掉工具调用与等待的成本。

### 产品能力增强后，哪些证据需要留下？

检索接口应保留原始网址和日期依据，编程助手应留下实际变更和运行结果，图片应用应能追踪内容处理与功能发布。它们对应不同场景，却有共同要求：发生问题时，维护者能找到可核对的记录，并据此修正流程。

本期没有将较早发布后于 10 月 17 日被重新整理的论文、模型或合作消息纳入，也未使用无法核实原始日期的传闻补足数量。
